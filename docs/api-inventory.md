## 3. Детальный разбор Endpoints

### 3.1. `GET /api/product/{code}` (`getProduct`)
- **HTTP-метод**: `GET`
- **Путь**: `/api/product/{code}`
- **Тег**: `catalog-controller`
- **Назначение**: Поиск и возврат карточки продукта по штрихкоду GTIN (`gtin`) или национальному коду товара NTIN (`ntinCode`).
- **Path-параметры**:
  - `code`: тип `string`, `required: true`. Описание в спецификации: *"Код продукта для поиска,gtin или ntinCode"*. Ограничения `minLength`, `maxLength`, `pattern` в схеме параметра отсутствуют.
- **Query-параметры**: отсутствуют.
- **Заголовки**: специальные заголовки в спецификации не объявлены.
- **Request Body**: отсутствует.
- **Response Body**:
  - Статус `200 OK`: контент объявлен с медиа-типом `*/*` (на практике Spring Boot REST контроллер по умолчанию сериализует объект `Product` в `application/json`). Схема: `#/components/schemas/Product`.
- **Ожидаемые ошибки**: в спецификации отсутствуют блоки `400`, `401`, `403`, `404`, `500` (зафиксировано в `docs/open-questions.md`).
- **Пагинация, фильтрация и сортировка**: не применимы (возвращается один объект `Product`, а не коллекция).
- **Потенциально изменяющие состояние операции**: нет (`GET` идемпотентен и безопасен).

### 3.2. `DELETE /api/product/download/time/` (`downloadTime`)
- **HTTP-метод**: `DELETE` (обратите внимание на завершающий слэш `/` в пути контракта)
- **Путь**: `/api/product/download/time/`
- **Тег**: `catalog-controller`
- **Назначение (`summary`)**: Очистка временной метки времени загрузки продукта.
- **Параметры (`path`, `query`, `header`, `body`)**: отсутствуют.
- **Успешный статус**: `200 OK` (без схемы тела ответа).
- **Потенциально изменяющие состояние операции**: **да** — сбрасывает системную метку времени загрузки/синхронизации каталога продуктов.

### 3.3. `DELETE /api/product/download/link/` (`downloadLink`)
- **HTTP-метод**: `DELETE` (обратите внимание на завершающий слэш `/` в пути контракта)
- **Путь**: `/api/product/download/link/`
- **Тег**: `catalog-controller`
- **Назначение (`summary`)**: Очистка текущей ссылки на загрузку продукта.
- **Параметры (`path`, `query`, `header`, `body`)**: отсутствуют.
- **Успешный статус**: `200 OK` (без схемы тела ответа).
- **Потенциально изменяющие состояние операции**: **да** — сбрасывает сохранённую ссылку на выгрузку/загрузку каталога продуктов.

## 5. Карта авторизации

- В `docs/openapi.json` **отсутствует** секция `components.securitySchemes`.
- На глобальном уровне спецификации и на уровне отдельных операций (`getProduct`, `downloadTime`, `downloadLink`) **отсутствует** секция `security`.
- Вывод по контракту: сервис спроектирован как внутренний микросервис без декларативной авторизации на уровне OpenAPI (либо авторизация терминируется на внешнем API Gateway / Ingress).
- Во фреймворке предусмотрен конфигурируемый `AuthProvider` (`NONE` по умолчанию, с поддержкой `BEARER`, `BASIC`, `API_KEY` через переменные окружения `AUTH_TYPE`, `API_TOKEN`, `API_USERNAME`, `API_PASSWORD`), что позволяет без изменения кода подключать авторизацию, если она включена на конкретном контуре.
